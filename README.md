# Mushin Lite

Mushin Lite is a lightweight state and persistence engine for LLM-driven interactive worlds.

The project separates world state from model output. Rather than relying on an LLM to remember everything, Mushin Lite maintains a canonical world state and applies rules to keep simulations consistent.

Current features:

- Canonical fact storage
- Slot-based state resolution
- Object persistence
- Room-based world model
- Movement and passage rules
- LLM packet extraction
- Runtime room generation
